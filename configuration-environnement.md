# Configuration de l'environnement de travail

## Objectif

L’objectif de ce travail est de configurer et valider le bon fonctionnement de l’environnement de développement nécessaire aux projets JavaScript.

Les logiciels requis sont :

- Git SCM
- Node.js
- NPM
- WebStorm

Chaque logiciel a été installé et testé à l’aide de commandes de vérification.

---

## 1. Git SCM

### Rôle
Git est un système de gestion de versions (VCS - Version Control System).  
Il permet de suivre les modifications du code, collaborer avec d'autres développeurs et gérer différentes versions d’un projet.

### Version requise
2.51.0 ou ultérieure

### Vérification de l'installation

Commande utilisée :

```bash
git --version
```

Résultat obtenu :

```
git version 2.45.1.windows.1
```

Git est correctement installé et fonctionnel.  
La version actuelle est légèrement inférieure à la version recommandée.

### Lien officiel
https://git-scm.com/

---

## 2. Node.js

### Rôle
Node.js est un environnement d’exécution JavaScript permettant d’exécuter du code JavaScript en dehors du navigateur.

### Version requise
22.18.0 ou ultérieure

### Vérification de l'installation

Commande utilisée :

```bash
node -v
```

Résultat obtenu :

```
v24.12.0
```

La version installée est conforme aux exigences.

### Lien officiel
https://nodejs.org/

---

## 3. NPM

### Rôle
NPM (Node Package Manager) est un gestionnaire de dépendances pour les projets JavaScript.  
Il permet d’installer, mettre à jour et gérer les bibliothèques et frameworks nécessaires au développement.

### Version requise
11.5.2 ou ultérieure

### Vérification de l'installation

Commande utilisée :

```bash
npm -v
```

Résultat obtenu :

```
11.6.2
```

La version installée est conforme aux exigences.

### Lien officiel
https://www.npmjs.com/

---

## 4. WebStorm

### Rôle
WebStorm est un IDE (Integrated Development Environment) spécialisé dans le développement JavaScript et Node.js.

Il permet :
- L’édition intelligente du code
- Le débogage
- L’intégration avec Git
- La gestion de projets Node.js

### Version requise
2025.2 ou ultérieure

### Vérification de l'installation

La version peut être vérifiée dans le menu :

Help > About

La version installée doit être 2025.2 ou ultérieure.

### Lien officiel
https://www.jetbrains.com/webstorm/
